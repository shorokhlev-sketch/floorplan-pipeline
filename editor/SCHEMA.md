# План v3 — формат документа `plans/unit-N.json`

Источник истины для планировки. Импортёр (`tools/plan-import.py`) создаёт его один раз из PDF архитектора,
дальше документ живёт своей жизнью в редакторе. Рендер (`render.js`) — чистая функция документ → SVG.

Координаты: **pt плана этажа** = координаты PDF минус `bbox[0..1]` этажа из `plan-studio/data/floor-F.json`.
1 pt = 7,05 см. Ось Y вниз (как в PDF/SVG). Округление до 2 знаков.

```jsonc
{
  "v": 3,
  "unit": "202", "floor": 2, "type": "studio",
  "title": "Студия", "total": 34.3, "living": 29.1, "balcony": 5.2,   // подписи — данные, не геометрия
  "bbox": {"x0": 304.8, "y0": 167.9, "w": 82.5, "h": 162.7},          // кадр рендера; редактор пересчитывает по геометрии + margin

  "nodes": {"n1": [318.8, 208.1], "n2": [318.8, 227.9]},            // общие вершины стен

  "walls": [
    {"id": "w1", "a": "n1", "b": "n2", "t": 3.2, "side": 1, "kind": "exterior"}
  ],
  // Стена = опорная линия a→b + толщина t, выдавленная на ОДНУ сторону.
  // u = (b−a)/|b−a|; perp(u) = (−u.y, u.x); нормаль выдавливания n = side · perp(u), side ∈ {1, −1}.
  // Опорная линия у наружных стен = внутренняя грань (сторона комнаты): так узлы соседних стен совпадают
  // при разной толщине, а ступеньки толщины остаются на стороне комнаты (правило заказчика: наружная грань прямая).
  // kind: exterior | corridor | party | partition | balcony | railing. Рендер всех kind одинаков (заливка ink),
  // kind нужен редактору (пресеты толщин) и будущим стилям (railing может стать штриховкой).

  "openings": [
    {"id": "o1", "wall": "w1", "pos": 12.4, "width": 9.0, "kind": "door", "hinge": "a", "swing": -1},
    {"id": "o2", "wall": "w7", "pos": 0.0,  "width": 7.7, "kind": "window"},
    {"id": "o3", "wall": "w9", "pos": 3.0,  "width": 18.0, "kind": "sliding"}
  ],
  // pos — от узла a вдоль опорной линии, pt; width — ширина проёма. Проём вырезает стену при рендере.
  // door: полотно (ink 0.5) от петли, дуга (muted 0.4, пунктир 1.5/1.5). hinge — у какого узла петля,
  //       swing — с какой стороны дуга: +1 = на стороне n (выдавливания), −1 = противоположная.
  // window: стена вырезана, в проёме две тонкие линии (ink 0.5) по граням + опционально центральная (style.window).
  // sliding: два полотна со смещением, без дуги. passage: просто проём.
  // jambs: true — рисовать чёрные косяки по краям проёма (опционально).

  "areas": [
    {"id": "r1", "kind": "room", "name": "", "poly": [[318.8, 208.1], ...],
     "label": {"text": "29,1", "x": 330.3, "y": 277.1}},
    {"id": "r2", "kind": "balcony", "poly": [...], "label": {"text": "5,2", "x": 340.8, "y": 312.5}}
  ],
  // Заливка: room → floor_fill, balcony → paper (белый), shaft → paper. Подпись — данные (текст + якорь baseline-left);
  // рисуется отдельным финальным проходом рендера (opts.labels). Площадь по полигону: |A| · 0.0705² м² — подсказка в редакторе.

  "columns": [{"id": "c1", "x": 313.1, "y": 288.9, "w": 8.5, "h": 8.5}],   // белый прямоугольник, обводка ink 0.9

  "blocks": [
    {"id": "b1", "sym": "raw", "x": 350.5, "y": 211.9, "w": 20.7, "h": 17.8, "rot": 0, "mirror": false,
     "paths": [{"d": "M 20.7 0 L 0 0 L 0 9.2 …", "fill": "paper", "stroke": "ink", "w": 0.5}]},
    {"id": "b2", "sym": "bed_double", "x": 340.0, "y": 240.0, "w": 22, "h": 32, "rot": 90, "mirror": false}
  ],
  // Блок = локальная система координат (0,0 — левый верх, w×h), затем rot (0/90/180/270 вокруг центра) и mirror (по X).
  // sym: "raw" — пути из PDF (paths обязательны); иначе имя символа из symbols.js, paths пусты.
  // Цвета в путях — токены: "ink", "paper", "floor", "muted" или hex. fill/stroke могут быть null.

  "notes": [
    {"id": "k1", "kind": "pen", "pts": [[x, y], ...]},
    {"id": "k2", "kind": "text", "x": 0, "y": 0, "text": "тут дверь не туда"}
  ]
  // Красные замечания для заказчика. В экспорт не идут (opts.notes=false).
}
```

## Инварианты (проверяет `validate()` в импортёре и API)

- все `walls[].a/b` существуют в `nodes`; `a != b`; длина > 0.05;
- все `openings[].wall` существуют; `0 ≤ pos` и `pos + width ≤ длина стены + 0.05`; `width > 0`;
- `areas[].poly` ≥ 3 точек; `blocks[].sym == "raw"` ⇒ `paths` непуст;
- id уникальны внутри своей коллекции.

## Рендер (render.js) — порядок слоёв

paper → areas (пол, балкон) → стены (куски между проёмами, одна заливка ink, без обводки; концы, упирающиеся в
другую стену, продлеваются на 0.4 pt внутрь неё, чтобы не было швов антиалиасинга) → проёмы (окна, полотна, дуги)
→ колонны → блоки → [подписи] → [замечания].
